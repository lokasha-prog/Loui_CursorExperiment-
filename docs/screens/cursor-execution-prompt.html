Sprint Execution Loop (Steps 1-30)

For each sprint, follow this exact 7-step loop. Do NOT batch sprints.

1READ THE SPEC

Open spec-19-roadmap-sprints.html, find Sprint N, read deliverables + linked spec files.

2READ THE VISUAL TARGET

Open corresponding screen-*.html or mobile-*.html. Match layout, components, data, interactions.

3IMPLEMENT

Follow .cursorrules conventions. Backend: entities → EF config → migration → DTOs → handlers → controllers → tests. Frontend: OpenAPI client → TanStack hooks → components matching mockup → tests.

4ENFORCE NON-NEGOTIABLES

tenant_id + RLS on every entity. Parent-child ownership (404 not 403). CSS logical properties only. All strings via t('key'). Money as integer fils. Audit log on every mutation. 80/75/70% test coverage.

5RUN TESTS

dotnet test, pnpm test (web + mobile). All must pass before commit.

6UPDATE PMO DASHBOARD

Edit PROJECT_STATE in project-pmo.html: mark sprint done, set next active, update overallPct. Commit.

7GIT COMMIT + SUMMARY

Conventional commit: feat(<module>): <desc>. Summarize what was built, files changed, tests added, next sprint preview.

Critical Rules (Do Not Violate)

📚 Read Before You Code

Always read the relevant spec file + visual mockup before implementing. Specs are authoritative.

📊 Update PMO After Every Sprint

Open project-pmo.html, edit PROJECT_STATE, commit. Dashboard is source of truth.

🏃 One Sprint at a Time

Never batch. Complete one fully (tests + PMO + commit) before starting next.

🎨 Match the Visual DNA

Terracotta + sage + amber. Fredoka + Nunito + JetBrains Mono. Match screen-*.html mockups.

🌐 Bilingual + RTL First-Class

t() for all strings. CSS logical properties. JSONB i18n. Test LTR + RTL.

🔐 Multi-Tenancy + Ownership

tenant_id + RLS on every entity. Parent-child ownership → 404 not 403.

✅ Tests Required

80% backend, 75% web, 70% mobile. Unit + integration + E2E. All pass before commit.

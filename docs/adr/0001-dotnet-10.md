# ADR-0001: Backend targets .NET 10 instead of .NET 8
- Status: Accepted (owner decision, 2026-10-20)
- Context: Spec 05 locks .NET 8. Only .NET 9/10 SDKs are installed; .NET 8 reaches end of support Nov 2026.
- Decision: Target net10.0 (LTS), C# 14, EF Core 10. All other stack choices unchanged.
- Consequences: Package versions follow .NET 10 releases; spec text saying ".NET 8" should be read as ".NET 10".
